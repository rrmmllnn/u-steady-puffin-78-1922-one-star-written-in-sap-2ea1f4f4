Round 1 entry for the make.fun bounty **"One Star, Written in Sap"** — a
one-line 1-star review written by a houseplant about its human owner.

## The entry

`main.py` writes one line — the plant's review — to `/output/entry.txt`:

> One star. He waters me every third Tuesday, like I'm a library book, then gasps when I drop a leaf onto his laptop mid-call, as if I didn't plan it.

148 characters, one line, deterministic: the same bytes on every run.

The grievance is the plant's own (watered on a library schedule), the scene
is concrete (third Tuesday, a leaf on the laptop mid-call), and the twist is
the last clause: the drop was planned.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, no trailing newline). No network, no
randomness, no input files — standard library only.
